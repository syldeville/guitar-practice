# Fretlog — guitar practice tracker

A small iPhone-friendly web app for working through the 10 levels of
"What to Learn on Guitar in Order": tick off skills you're confident with,
work through recommended songs and YouTube lessons, and log practice days
on a calendar with streaks.

**Use it:** open https://syldeville.github.io/guitar-practice/ in Safari →
Share → Add to Home Screen.

Data is stored on your phone only (localStorage). Use the Backup tab to save
a backup file to Files / iCloud Drive now and then.

Content lives in `levels.js`. When you change app files, bump `VERSION` in
`sw.js` so installed copies pick up the update.
